# 听写 · Ink & Echo

面向 Android 手机的单词听写软件。播放在线单词音频并保存在本机，在纸上作答，结束后对照答案并标错。无需安装系统 TTS 引擎或语音包。

## 安装与使用

安装文件：[InkAndEcho-1.0.3.apk](releases/InkAndEcho-1.0.3.apk)。支持 Android 7.0 / API 24 及以上，无需账号。已安装旧版的手机可直接覆盖安装，保留词表、记录与发音缓存；不要先卸载旧版。

1. 把 APK 发送到手机，打开文件并按系统提示允许当前文件来源安装应用。
2. 首次使用请联网，进入「设置 → 试听发音（apple）」，确认媒体音量合适。无需设置系统文字转语音。
3. 首页已有 Unit 1 / Lesson 1；也可以新建单元与听写框。
4. 在目标框中导入 `.docx`、UTF-8 / GBK `.txt`，或粘贴文本。检查预览后确认导入。
5. 选择全部、区间、手动勾选、错词、到期复习、从未听过或本轮未听；选择有序或随机，开始听写。所选发音全部准备好后才创建听写记录；进度窗口可取消，已下载文件会保留，失败可重试。
6. 软件只显示题号、进度和控制按钮。听音后写在纸上，再点下一题；支持重播、跳过、恢复跳过题、上一题、提前结束。
7. 对改页只需勾选「标错」。未标错且未跳过的题在完成对改后视为正确。历史页面可补标与撤销。

## 已实现

- 单元分组；听写框新建、重命名、移动、排序、复制词条和级联删除。
- DOCX 正文解析；TXT UTF-8 / GBK 检测；粘贴导入；序号清洗；预览编辑和排除；同框大小写敏感判重；事务导入。
- 多种选词范围；随机 / 有序；全量覆盖；冻结保存题序；全局单批次锁；每题进度保存与中断恢复。
- 有道在线单词音频 + 本地 MP3 缓存；美音 / 英音分别缓存；语速、播放次数、间隔、自动下一题和常亮设置。切换题目、退出或进入后台会停止播放与等待任务，下载或播放失败不会自动跳到下一题。
- 只标错、即时保存、幂等设置状态、撤销流水、历史补标、聚合统计与复习计划重算。
- 错词优先、到期词优先、连续答对衰减、1 / 2 / 4 / 7 / 15 / 30 天复习计划。
- 当前框错词清单、筛选与排序、错误次数、连续答对、最近错误、到期日期和标记清除。
- 当前框统计、历史、最近 10 次正确率与错题数趋势、TOP 20 错词。
- 中英双语、跟随系统语言；本地 SQLite 持久化；释义缓存。
- 1.0.2 视觉调整：圆头声波和线条图标、自适应桌面图标、胶囊按钮、较大圆角的卡片与输入框、圆角弹窗及进度条，按钮增加轻触反馈。
- 1.0.3 修正成组按钮的底边裁切：将顶部间距移到整行，关闭按钮行的文字基线对齐，按钮和点击反馈统一使用随实际尺寸形成完整圆边的胶囊背景。
- 可选择启用在线英汉释义，使用有道公开词典，最多 3 个并发请求、失败重试一次、无结果占位与手动重试。首次启用前说明词条会发给第三方。

## 采用的实现决定

需求文档中的待定项按可调整的默认值实现，没有要求用户重新逐条确认。

- 技术栈：原生 Android Java + 系统 UI、SQLite、MediaPlayer，无第三方运行时依赖。文档中的 Flutter 属于技术建议；此实现交付 APK。
- 按用户后续要求替换 Q16 的系统 TTS：使用 HTTPS 获取有道发音，词条会发送给该服务，听写记录和标记保留在本机。首次下载需联网；已缓存词条可离线使用。新口音需要单独下载。释义开关只控制释义查询，不影响发音下载。
- 默认 Android 7.0+、美音、0.9 倍语速、播放 1 次、手动下一题、错词偏向开启。
- 「跳过不计正确率」按确认的 Q15 执行：正确率 = 正确题数 ÷ 未跳过题数；全跳过显示「—」。文档中以全部题数作分母的一处公式未采用。
- 提前结束时，尚未进入的题目自动跳过，不会误计为答对。
- 对改中的错误立即影响错误统计；未标错题目在确认完成对改后才推进正确连续次数与复习。撤销临时标记会恢复原状态。
- 简化复习采用固定间隔表，不按难度系数额外缩放。默认每个词只出一题；数据结构允许一批多题对应同词，没有自动追加错词重听。
- 在线词典默认关闭，启用后自动查询并缓存，不需要申请密钥。公开服务没有可用性保证，没有结果时仍能完整完成对改。
- 不实现账号、云同步、备份、导出、自动判分、跨框统计或定时提醒。

## 验证状态与限制

- 核心规则：`tests/CoreTests.java`，121 项断言通过，覆盖导入、DOCX 段落/文本片段、判重、随机覆盖、优先区、复习日期、跳过和回滚。
- 发音缓存：`tests/AudioCacheTests.java`，46 项断言通过，覆盖离线复用、重启后缓存、口音隔离、编码、有限重试、下载中断、取消、损坏缓存、无效响应、超大文件和并发复用；另用实际下载的两份 MP3 验证缓存接收，合计 48 项。
- 数据库集成：`tests/StoreTests.java`，52 项断言通过。未修改的生产 `Store` 通过轻量 Android 接口适配器运行在真实 SQLite 上，验证幂等标错、历史重算、跨框隔离、单批次锁、事务失败全回滚、级联删除、缓存及关闭重开后的持久化。
- APK 已完整编译，Android 资源和 Manifest 可解析，v2 / v3 签名验证通过。
- 公开词典已用 `apple` 实际请求，返回了 `n.` 和中文释义。
- 发音服务已实际下载 `apple`（美音）与 `look forward to`（英音）；两者均返回 `audio/mpeg`，通过 MP3 格式和解码检查。新旧 APK 签名证书一致。
- 尚未完成真机或模拟器安装、界面与触摸操作测试。当前 Windows 的 ADB 默认用户目录受到权限限制。不能据此确认具体手机兼容性、启动时间或发音延迟。
- 未验证文档规定的 8000 词真机性能指标；列表每次追加 50 项，当前实现仍在本地加载当前框词表。该版本属于可安装试用的第一版。
- 首次发音下载依赖第三方服务及网络；未缓存的词在断网时无法发音。缓存保存在应用私有文件目录，不随系统临时缓存清理而丢失；卸载会删除。
- 本地数据随卸载删除。使用系统文件选择器，无需存储目录全盘权限。

## 源码与构建

源码位于 `app/src/main/java/com/inkecho/dictation/`：

- `Engine.java`：纯业务规则、题序、复习与统计回放。
- `WordImport.java`：词条清洗、编码检测和 DOCX 解析。
- `Store.java`：SQLite 表、约束、事务、聚合、持久化。
- `Translations.java`：并发限流、在线查释义与缓存。
- `AudioCache.java`：HTTPS 发音下载、MP3 校验、取消及本地音频文件复用。
- `MainActivity.java`：双语界面、文件选择、音频播放、批次发音准备和用户流程。

可用 Android Studio 打开本项目，使用 JDK 17、Android SDK 35、Android Gradle Plugin 8.7.3 构建。Gradle 配置未依赖任何业务库；该方式需本地 Gradle 或由 Android Studio 提供 Gradle。

本项目已使用官方 JDK / Android SDK 工具直接构建，无需 Gradle 下载依赖：

```powershell
./scripts/build.ps1
./scripts/test-store.ps1
```

当前构建工具下载在被 Git 忽略的 `.tools/` 中。重新准备环境时，构建脚本默认读取以下路径，也可以通过 `INK_ECHO_JAVA`、`INK_ECHO_BUILD_TOOLS`、`INK_ECHO_ANDROID_JAR` 指定位置：

```text
.tools/java/<JDK 17 folder>/
.tools/sdk-build/android-15/             # Android Build-Tools 35
.tools/sdk-platform/android-35/android.jar
```

SQLite 主机集成测试还使用 `.tools/sqlite-jdbc.jar`（3.47.1.0）、`.tools/slf4j-api.jar` 和 `.tools/slf4j-nop.jar`（2.0.16），仅供测试，不会进入 APK。

首次构建自动生成 `.tools/development.jks`，用开发证书签名。保留此文件可继续覆盖安装后续版本；丢失证书无法更新已安装的同包名应用。当前证书密码是开发默认密码，不用于应用商店发布。
